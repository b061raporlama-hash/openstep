# OpenSteps v0.3.0

Interactive offline HTML guides, a floating recording island, and recording performance improvements.

- Stop recording from the top-center island, which shows the current step count and stays above application windows without taking focus.
- Stopping opens the HTML save dialog directly. Saved guides remain available for editing and exporting later.
- Export one portable HTML file with embedded screenshots, Turkish viewer controls, thumbnails, zoom, fullscreen, keyboard navigation, and a manual slideshow.
- Preserve step order, edited screenshots, multiline descriptions, and steps without screenshots. Exported user text is displayed safely as text.
- Reduce editor preview bitmap memory and avoid rebuilding the entire hidden editor after each recorded step.
- Move click-target UI Automation lookup off the UI thread and bound descendant searches.
- Fix capture-mode labels, wrapped option descriptions, and Windows tray-overflow click filtering.

## Download and run

Download **OpenSteps-v0.3.0-win-x64.exe** and run it on Windows 10 or newer (x64). It includes the .NET runtime; no separate .NET installation is needed. This is a portable application and does not create a Start menu entry.

The ZIP contains the same executable, README, and license. The `.sha256` files contain the corresponding download checksums.

## Validation

108 automated Windows tests cover Core export, image preservation, control rendering, recording task completion, preview sizing, and native island window behavior. Local native window fixtures include normal/maximized windows and topmost recovery after 120 step-count updates. These checks do not represent exhaustive testing of every third-party application.

OpenSteps remains an unsigned Windows beta. Review screenshots before sharing guides.
