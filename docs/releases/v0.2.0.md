# OpenSteps v0.2.0

Windows x64 release with **Export as Single HTML**.

- Export a guide as one offline HTML file with embedded screenshots and styles.
- Keep current step order, edited titles, descriptions, and the final cropped, redacted, annotated, or replaced screenshots.
- Preserve existing Markdown and multi-file HTML export options, including combined exports.
- Escape user text in HTML. No JavaScript, external assets, telemetry, or uploads are added to the exported report.

## Download and run

Download `OpenSteps-v0.2.0-win-x64.zip`, extract the entire archive, and run `OpenSteps.App.exe` on Windows 10 or newer. The package includes the .NET runtime; no separate .NET installation is needed. Keep the extracted files together.

To create only one HTML file, open **Export**, clear **Markdown** and **HTML**, then select **Export as Single HTML**. Copy `guide-single.html` wherever you need it; no accompanying image folder is required.

The `.sha256` asset contains the ZIP checksum.

## Beta limitations

OpenSteps remains an unsigned Windows beta. SmartScreen may warn on first launch. Review screenshots before sharing. Windows desktop recording, WPF interaction, and offline opening in Edge and Chrome still require manual verification; the checklist is in `docs/manual-smoke-test.md`.
